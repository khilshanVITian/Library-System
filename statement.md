# Project Statement

## Problem Statement
Managing books manually can make it difficult to track available books, members, issued books, returned books, and transaction history. This project provides a simple computerized library management system.

## Scope
The system manages:
- Books
- Library members
- Book issue and return transactions
- Basic reports
- Persistent JSON storage

## Target Users
- Librarian
- Library administrator
- Students using the library

## High-Level Features
1. Book management
2. Member management
3. Issue and return management
4. Search
5. Reports
6. Data storage
7. Validation and testing

## Objectives
- Apply Python programming concepts to a real-world problem.
- Use lists and dictionaries to organize data.
- Use functions and modules for modular programming.
- Implement CRUD-style operations.
- Add validation, error handling, storage, and testing.
